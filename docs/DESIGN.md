# 디자인 원칙

룰북이 다루지 않는 **"왜"** 만 담는다. 규칙은 여기 쓰지 않는다 — 중복되면 원본과 어긋난다.

> ⚠️ **이 문서는 아직 비어 있다.** 아래 항목은 코드나 Figma에서 도출할 수 없고 사람이 정해야 한다. 채워지기 전까지는 "디자인 원칙에 따르면…" 같은 근거로 쓰지 마라. 판단이 필요하면 사용자에게 물어라.
